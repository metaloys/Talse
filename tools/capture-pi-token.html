Capture Pi Access Token (local)

Security warning: this page displays your Pi access token in plain text. Run locally, copy the token, then close the page. Do NOT paste tokens into public places.

Steps:

  1. Click Load SDK to load Pi SDK.
  2. Click Authenticate and complete the Pi auth flow in the popup/iframe.
  3. Copy the value shown in the box below. Store it securely or paste into your test commands.
SDK URL: https://sdk.minepi.com/pi-sdk.js
